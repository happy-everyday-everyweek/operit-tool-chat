# Operit Tool Chat

Operit AI 的局域网聊天小工具 —— 极简纯文字风格的前端页面。

通过 Operit 的 `/api/web/` 完整接口实现同一局域网内跨设备消息收发与历史记录同步。

## 功能

- 跨设备同步历史消息（数据存储在 Operit 服务端）
- 多会话管理（切换 / 新建 / 删除对话）
- SSE 流式接收 AI 回复（打字机效果）
- Markdown 渲染（粗体、代码块、引用、列表等）
- 工具调用内容自动过滤（只显示纯文本）
- 暗色极简界面，无多余装饰
- 消息分页加载（滚动加载更多）

## 使用方式

### 1. 启动静态文件服务器

```bash
python3 -m http.server 8925 --bind 0.0.0.0
```

### 2. 访问页面

- **本机**: `http://127.0.0.1:8925/chat.html`
- **其他设备**: `http://<手机实际IP>:8925/chat.html`

### 3. 配置

页面自动从当前 URL 推断 API 地址（`http://<当前IP>:8094`），适配 Operit 服务端。

如需修改 Token，编辑 `chat.html` 中的 `TOKEN` 变量。
